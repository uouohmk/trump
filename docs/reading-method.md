# 천체와 사주를 생활 조언으로 풀어내는 기준

검토일: 2026-09-13. 운세는 전통적인 상징을 참고해 작성한 오락용 해석이다. 실제 천체 좌표의 계산과 미래 사건의 예측은 별개다.

## 천문지도

태양은 자기표현, 달은 감정, 수성은 대화와 배움, 금성은 관계와 취향, 화성은 행동, 목성은 성장과 가능성에 대응한다. [Astrodienst의 행성 설명](https://www.astro.com/astrology/in_planets1_e.htm)을 참고했다. 생활 행동으로 옮긴 문장은 이 사이트에서 작성한 현대적인 제안이다.

한국 시간 자정의 지심 황경을 Astronomy Engine으로 계산한다. 각 천체의 황경을 출생 시 태양 황경과 비교한다. 이전의 별자리 중앙값(15°) 기준을 실제 출생 태양 위치로 바꿨다. 출생 시간을 모르면 현지 출생일 중 유효한 첫 시각과 마지막 시각의 태양 위치 범위를 사용한다. 범위 양끝의 각도 분류가 다르면 ‘출생 시간에 따라 달라짐’으로 표시하고 길흉을 확정하지 않는다. 지도에서 이 경우의 기준선은 범위의 가운데를 표시한다.

각거리의 기준은 0°, 60°, 90°, 120°, 180°이고 허용 범위는 이 사이트에서 정한 6°다. 60°·120°는 조화를 활용할 때, 90°·180°는 조정할 때, 0°는 해당 주제에 관심을 둘 때로 풀이한다. 0°를 무조건 좋은 운으로 처리하지 않는다. 가까운 주요 각이 없으면 특별한 길흉을 붙이지 않는다. [Astrodienst의 주요 각과 허용각 설명](https://www.astro.com/astrology/in_aspect_e.htm)을 참고했으며, 허용각과 구체적 생활 문장은 사이트의 설계 선택이다.

질문의 주제에 맞는 천체 중 가장 가까운 주요 각을 우선한다. 연애는 금성과 달, 일은 수성·화성·목성, 돈은 금성과 목성, 사람은 수성·금성·달, 도전은 화성·목성·태양을 살펴본다. 이는 개별 주제에 답하기 위한 간략한 편집 규칙이며 전체 출생 차트나 하우스 해석이 아니다. 상승궁, 하우스, 역행, 현재 천체끼리의 각도는 이 버전에서 해석하지 않는다. 지도 선의 길이는 거리가 아니다.

## 사주

출생 일간과 해당 날짜의 천간을 오행의 생성·제어 방향과 음양으로 비교해 십성을 계산한다. 같은 오행은 비견·겁재, 내가 생하면 식신·상관, 내가 극하면 편재·정재, 나를 극하면 편관·정관, 나를 생하면 편인·정인이다. 예를 들어 갑에게 경은 편관, 을에게 경은 정관이므로 일간을 바꾸면 분류가 달라진다.

계산 규칙과 전통의 구분은 저장소의 [사주 해석 참고서](../skills/astronomy-astrology/references/saju-divination-research.md) 4~5절과 [『연해자평』](https://zh.wikisource.org/wiki/淵海子平)을 따른다. 협력·표현·자원 관리·책임·배움이라는 현대적 주제를 통해 일, 관계, 주의점 카드를 제공한다. 십성의 이름 자체를 사건의 길흉으로 읽지 않는다.

일간과 당일 천간만 비교한 간단한 조언이다. 월령·지장간·통근·격국·용신·대운을 종합한 통변을 구현했다고 주장하지 않는다. 오행 막대그래프는 별도의 구성 설명이며, 오행 개수를 행운 점수나 직업 적성으로 환산하지 않는다. 기존 DB 기록은 소유자의 요청대로 보존하지만 새 UI에서는 조회하지 않는다. 새 상담은 브라우저 메모리에서만 처리하며 서버 전송과 영구 저장을 하지 않는다.

## 화면 순서

상담 준비 → 출생 정보 입력 → 입장 → 커튼 열림과 상반신 마녀 등장 → 카드가 차례로 확대되며 나타남 → 별의 등장 → 별자리 선 연결 → 천체별 운세와 사주 조언.

장면과 카드 이동에는 짧은 페이드 전환을 사용한다. 동작 줄이기 설정에서는 전환 지연과 애니메이션을 없애고 모든 별과 선을 즉시 보여준다. 입장 연출에는 건너뛰기 버튼을 제공한다.

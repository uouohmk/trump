# 사주 심층 해석·기록 절차

이 문서는 [심층 연구](saju-divination-research.md)를 실제 응답과 기록에 적용하는 절차다. 아래의 작업 순서와 필드 구성은 스킬 설계 원칙이며, 단일 고전에서 그대로 옮긴 보편 규칙이 아니다. 인물·사건 관리에는 [기록 지침](fortune-records.md)을 함께 따른다.

## 1. 먼저 요청을 분류한다

| 요청 | 필요한 자료 | 수행 범위 |
|---|---|---|
| 개념·문헌사 설명 | 심층 연구의 관련 절·원출처 | 출생 정보 없이 설명 |
| 제공된 팔자 해석 | 원국 원문, 출처, 해석 질문 | 제공값과 독립 검증 여부를 구분 |
| 새 명식 산출 | 출생일·달력·윤달·시간 정확도·필요 장소 | 계산 가능한 값만 산출 |
| 기간 운세 | 검증 상태가 기록된 원국, 대상 기간, 운 계산 규칙 | 원국과 운의 관계를 조건부 설명 |
| 두 사람 궁합 | 두 인물의 자료·계산 버전·관계 맥락 | 두 체계의 결과와 실제 보고를 구분 |
| 기존 기록 갱신 | 기존 파일·식별자·새 자료 | 과거 기록과 판정을 보존하며 새 버전 추가 |

일반적인 설명에 개인 자료를 요구하지 않는다. 제공되지 않은 이름·출생시각·성별·관계 상태를 생성하지 않는다.

## 2. 계산에 앞서 규칙을 고정한다

규칙 세트에는 다음을 필요한 만큼 기록한다.

- 양음력·윤달 변환 출처와 적용 가능한 날짜 범위.
- 연주·월주 경계와 사용한 절입 시각.
- 일주 날짜 변경 기준, 자시·야자시 처리.
- 표준시 또는 태양시 기준, 역사적 시간대, 적용한 보정.
- 대운을 구할 경우 순역·기산 절·환산·반올림·나이 표기.
- 계산 도구·버전·계산일.

규칙이 고정되지 않은 채 도구마다 다른 명식이 나오면 평균 내지 않는다. 입력이 같은지 → 달력 변환 → 연·월 경계 → 일·시 경계 → 도구 설정 순서로 원인을 좁힌다.

계산 상태는 **미계산 / 사용자 제공·미검증 / 계산 완료 / 대조 확인 / 조건별 복수 후보 / 계산 보류**처럼 뜻이 분명한 말로 기록한다. “대조 확인”에는 무엇과 무엇을 대조했는지 붙인다. 도구 이름만 적고 검증 완료라고 하지 않는다.

## 3. 원국의 구조를 먼저 적는다

1. 연·월·일·시의 간지와 일간을 기록한다. 미정인 기둥은 그대로 둔다.
2. 천간, 지지의 대표 배속, 지장간을 구분한다.
3. 십성은 일간에 대한 오행·음양 관계로 산출한다. 지지는 어떤 지장간을 기준으로 요약했는지 밝힌다.
4. 월령과 계절, 통근·투간, 생조·설기·극제 관계를 적는다.
5. 형충회합은 대상 글자와 위치를 먼저 기록하고, 작용·변화의 성립 여부는 별도로 판단한다.
6. 이후에 선택한 해석 경로의 격국·용신·운을 검토한다.

오행 숫자는 계산 층을 명시한 요약에만 쓴다. 부족한 수를 채워 5개 오행을 같게 만드는 것을 기본 용신 공식으로 사용하지 않는다.

## 4. 문헌과 해석 경로를 선언한다

사용자가 기존 유파·판본을 지정했다면 우선 따른다. 지정이 없고 심층 풀이가 필요하면 “자평명리의 일간·월령 중심 구조를 우선하고, 필요할 때 강약·조후를 별도 검토한다”고 밝힌다. 이 순서는 스킬의 기본 운영 선택이며 유파 간 합의라는 뜻은 아니다.

격국은 후보 → 성립 근거 → 훼손 조건 → 구응의 유무 순으로 검토한다. 억부·조후·통관·병약 관점을 덧붙일 때는 각 관점이 답하는 질문을 적는다. 출처가 확인되지 않은 종격·화격 요건이나 지장간 가중치를 새로 만들어 적용하지 않는다.

### 용신 판단을 저장할 때

| 필드 | 내용 |
|---|---|
| 용신의 정의 | 월령·격국의 중심 / 강약 조절 / 기후 조건 등 실제 사용하는 뜻 |
| 문헌·경로 | 책·판본·장·쪽 또는 URL, 현대 해석이면 그 표시 |
| 후보 | 글자·오행·십성·기능 중 무엇을 뜻하는지 |
| 판단 근거 | 월령·통근·투간·생극 등 확인한 구조 |
| 반대 근거·예외 | 후보의 작용을 약화하거나 바꾸는 조건 |
| 상신·희기 | 해당 문맥에서의 역할과 조건 |
| 결론 상태 | 채택 / 조건부 / 복수 후보 / 판단 보류 |

원전의 “用神”과 현대의 “도움이 되는 오행”이 다른 뜻이면 원문 용어·정규화 용어를 함께 보존한다. 길신·흉신이라는 이름만으로 사람이나 사건의 좋고 나쁨을 확정하지 않는다.

## 5. 시간과 관계를 추가한다

원국과 대운·세운·월운의 항목을 구분해 표시한다. 대운 기산이 미정이면 특정 날짜부터의 대운 해석도 미정으로 둔다. 연간·월간 운세는 실제 날짜 범위를 적고, 경계 규칙 차이로 해석이 달라지면 조건별 결과를 제시한다.

궁합에서는 두 사람의 개별 구조를 먼저 확인한다. 한쪽의 용신이 다른 사람에게 있다는 사실을 바로 관계 성공의 보증으로 쓰지 않는다. 일간·일지의 관계, 기타 합충 등을 사용했다면 어떤 궁합 규칙을 채택했는지 밝혀야 한다.

서양 점성술과의 통합은 같은 인물·질문·기간에서 병렬로 수행한다. 사주의 합충을 실제 천체의 각거리로 계산하지 않고, 사주의 십성을 서양 행성 위치로 대체하지 않는다.

## 6. 결과는 근거가 보이는 문장으로 쓴다

응답 분량은 질문에 맞춘다. 심층 개인 풀이에서는 다음 순서를 기본으로 한다.

1. 입력·계산 상태와 확정 가능한 범위.
2. 원국의 주요 구조와 사용한 해석 체계.
3. 격국·용신 등의 후보, 채택 근거, 반대 조건.
4. 요청한 기간·관계에 대한 전통적 해석.
5. 실제 생활에서 확인할 질문과 알려진 사실.
6. 출처·미확정 항목·대안 해석.

“甲 일간에 庚은 칠살로 분류된다”는 분류 문장이다. “압박·규율이라는 주제로 읽어 볼 수 있다”는 현대적 해석 문장이다. “사용자가 최근 업무 부담을 보고했다”는 생활 기록 문장이다. 세 문장을 서로의 증명으로 바꾸지 않는다.

십이운성의 병·사·절, 신살의 흉명, 격의 성패를 질병·사망·범죄·인간적 가치의 확정 판정으로 바꾸지 않는다. 고전의 성별·혼인 규범은 역사적 맥락을 표시하고 현재 인물에게 그대로 강제하지 않는다.

## 7. Markdown에서 DB·외부 출력까지 보존할 연결

인물 ID → 계산 버전 → 해석 규칙·출처 → 개인/관계 풀이 ID → 사건 ID의 연결을 유지한다. 각 해석 문장에 필요한 경우 다음을 덧붙인다.

- 구분: 전통 해석 / 현대적 설명 / 사용자 보고 / 계산 결과.
- 적용한 규칙과 출처.
- 성립 조건과 아직 확인하지 못한 조건.
- 작성일·대상 기간·당시 알고 있던 사실.

계산상의 미확정과 유파 간 의견 차이는 별도 항목이다. 숫자 신뢰도나 궁합 점수로 뭉치지 않는다. 사이트 출력 요청에는 이 구조를 자료 설계로 제안할 수 있지만, 실제 DB나 API를 구현·배포하지 않았다면 연결 완료라고 쓰지 않는다.

## 8. 전달 전 점검

- 일간이 바뀌면 십성 분류도 바뀌는지 확인했다.
- 오행 개수만으로 신강·신약·용신을 결정하지 않았다.
- 합의 조합과 합화 등의 작용 조건을 구분했다.
- 선택한 용신의 뜻과 문헌을 밝혔으며 다른 정의를 덮어쓰지 않았다.
- 신살·십이운성의 이름을 실제 사건으로 직역하지 않았다.
- 누락된 출생 정보와 절입·일시 경계 문제를 숨기지 않았다.
- 원문·현대 주석·스킬의 제안을 구분했다.
- 사후 사건을 본 해석을 사전 예측으로 집계하지 않았다.
- 존재하지 않는 계산 도구 실행·외부 저장·예측 정확도를 주장하지 않았다.

실제 기록에는 [운세·사주·궁합 양식](../assets/fortune-record-template.md)의 사주 심층 분석 구역을 사용한다.
